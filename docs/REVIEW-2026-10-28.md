## Bit-identity of factory presets

**Superseded by A8:** this check ran BEFORE Nik's −0.3 dBFS decision. Since the A8
fix, every preset renders ~2.4 dB lower on purpose, so HEAD vs work is no longer
bit-identical. The result below proves all the *other* fixes left the sound alone.

Exported `git archive HEAD` and the working tree to separate build trees, rendered all
16 factory presets the same way (fresh processor, `applyFactory(i)`,
`offlineRender(1500 ms)`), dumped raw float32, compared:

```
presets compared: 16   total float samples (head): 1152000
VERDICT: BIT-IDENTICAL across all presets    (max |diff| = 0.0 for every preset)
```

Controls: re-running the HEAD binary reproduced all 16 files byte-for-byte; flipping
one bit of one float in a copy tripped the comparator; `nm` confirmed the two binaries
really are different code (`resetParametersToDefaults`,
`removeNonFiniteParameterChildren`, `restoreTransientSampleFromState` present only in
the work binary). Caveat: this proves the fresh-instance, single-trigger factory path
is unchanged. B5/B3/B9 only diverge from a dirty state or an XML/preset load, which
that harness does not exercise — by design.
